# TRACK LOG - DỰ ÁN KIHO CAMERA (Cho thuê máy ảnh Quảng Bình)

Nhật ký theo dõi các cột mốc (milestones) phát triển website Kiho Camera.

| Milestone | Tên công việc | Trạng thái | Ghi chú |
|:---|:---|:---|:---|

| **M2** | Thiết kế Database Schema, RLS & Seed SQL |  Hoàn thành | `supabase/schema.sql`, `supabase/seed.sql`, RLS policies, Storage setup |
| **M3** | TypeScript Type Definitions & Database Services |  Hoàn thành | `src/types/database.ts`, `src/lib/services/*`, mock data fallback engine |
| **M4** | Xây dựng UI Components & Layout chung |  Hoàn thành | Header, Footer, Sticky Messenger Bar, ProductCard, Gallery, UseCaseSection |

| **M7** | Trang Chi tiết thiết bị `/thiet-bi/[slug]` |  Hoàn thành | Image gallery, Specs, Included items, Rental notes, Dynamic Messenger CTA |
| **M8** | Trang Feedback, Hướng dẫn thuê & Liên hệ |  Hoàn thành | `/feedback`, `/huong-dan-thue`, `/lien-he` |
| **M9** | Tối ưu SEO Onpage, Local SEO & Structured Data |  Hoàn thành | JSON-LD LocalBusiness & Product, dynamic sitemap.xml, robots.txt |
| **M10** | Hệ thống Admin Portal & Supabase Auth |  Hoàn thành | Login, Sidebar, Equipment CRUD, Category CRUD, Feedback CRUD, Settings |
| **M11** | Redesign UI/UX Photography Editorial & Motion |  Hoàn thành | Redesign toàn diện: Art direction editorial, Framer Motion, Typography contrast, Hairline dividers, bỏ cards-in-cards |
| **M12** | Tài liệu hướng dẫn, .env.example & Kiểm thử |  Hoàn thành | README setup, Deploy Vercel/Supabase, .env.example |
