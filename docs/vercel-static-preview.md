This also bypasses the old Next.js project defaults. Use an authorized commercial-capable Vercel project, link only the isolated folder, and deploy with `vercel deploy --target preview`. Never attach a domain, use `--prod`, or promote this preview under this task. No Vercel Preview has been uploaded yet.

On the actual Preview URL, use the existing static HTTP, SEO and browser checks. A protected Preview needs authorized browser/API access for those checks.
